# 🤖 Suite Multiuso de IA Generativa (Python + Streamlit + Gemini)

Una plataforma interactiva construida en Python que aprovecha la potencia de los modelos del lenguaje Gemini (`gemini-2.5-flash`) para ofrecer tres herramientas de IA Generativa en una sola interfaz web.

## ✨ Características

1. **✍️ Asistente de Redacción:** Genera textos personalizados según el tono y la extensión requerida.
2. **💻 Generador de Código:** Escribe y explica algoritmos en múltiples lenguajes de programación.
3. **💬 Chatbot Conversacional:** Mantén una conversación continua donde la IA recuerda el contexto anterior (`client.chats`).

## 🛠️ Tecnologías Utilizadas

- **Lenguaje:** Python 3.10+
- **Frontend / Interfaz:** Streamlit
- **Motor de IA:** Google GenAI SDK (`google-genai`)
- **Modelo LLM:** `gemini-2.5-flash`
